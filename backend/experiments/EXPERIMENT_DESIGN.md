# MADDx 多智能体辩论实验设计

## 1. 核心研究问题

**多模型异构辩论在医疗诊断任务上的准确率，是否优于单模型？是否优于纯投票集成？**

子问题：
- 多模型集成（投票）有增益吗？（ensemble effect）
- 多模型辩论的增益是否超出集成效应？（debate effect）
- 辩论轮数如何影响效果？（1 轮 vs 2 轮 vs 3 轮）
- 几个模型辩论最优？（2 个 vs 3 个 vs 4 个）

## 3. 评测数据集

### 3.1 数据集构成

CMB-Exam 测试集，选取 3 个考试类别，与参考论文对齐：

| 类别 | 单选题 | 多选题 | 合计 |
|------|--------|--------|------|
| 规培结业 | - | - | 400 |
| 执业医师 | - | - | 400 |
| 临床医学 | - | - | 400 |
| **总计** | **1108** | **92** | **1200** |

### 3.2 数据分配

| 阶段 | 题量 | 来源 | 目的 |
|------|------|------|------|
| Phase 1: 基线选型 | 1200 题全量 | 3 类别混合 | 选出最强模型 + 最佳辩论组合 |
| Phase 2: 辩论验证 | 1200 题全量 | 同上 | 辩论 vs 投票 vs 单模型 |

### 3.3 为什么与参考论文对齐

参考论文（袁嵩等, 2025）使用 CMB-Exam 中规培结业、执业医师、医学考研三个类别各 400 题——我们用临床医学替代医学考研（数据集中无此类别），保持了相同的 3×400=1200 题规模，结果表明可在同一基准上直接对比。

## 4. 评估指标

### 4.1 单选题（1108 题）

准确率 = 正确题数 / 总题数

单选题只有一个标准答案，精确率、召回率在单选题上退化为准确率。

### 4.2 多选题（92 题）

```
TP = 正确选中的选项数
FP = 错误选中的选项数
FN = 漏选的正确选项数

全局精确率 = ΣTP / Σ(TP + FP)
全局召回率 = ΣTP / Σ(TP + FN)
全局 F1     = 2 × P × R / (P + R)
```

全局聚合（macro-average over options）而非逐题平均，因为逐题计算在 TP=0 时会产生未定义的 P/R。

### 4.3 辅助指标

| 指标 | 用途 |
|------|------|
| 错误重叠率 | 两个模型答错同一题的比例（越低越互补）→ 选辩论组合 |
| 平均延迟 | 评估响应速度 |
| 修正率 | 辩论后被修正的错误比例（Phase 2） |
| 误伤率 | 辩论后被改错的比例（Phase 2） |

## 5. 核心变量

三个正交的独立变量：

| 变量 | 含义 | 取值 |
|------|------|------|
| 交互方式 | 智能体之间如何协作 | 投票（无通信）/ 辩论（有通信） |
| 辩论轮数 | 辩论中信息交换的次数 | 1 轮 / 2 轮 / 3 轮 |
| 智能体数量 | 参与诊断的模型个数 | 1 / 2 / 3 / 4 |

注意：投票没有"轮数"概念——每个模型独立答一次即聚合，同一模型在 temperature=0 下重复回答结果不变。

## 6. 实验分组

### 6.1 Phase 1：基线模型选型（1200 题全量）

**正在执行** — 确定最强单模型和最佳辩论组合。

```
实验组:
  Single × 4（每个模型独立答题，1200 题全量）

输出:
  - 4 模型准确率/P/R/F1 排名
  - 错误重叠矩阵
  - 推荐辩论组合（错误重叠率最低 + 综合得分最高的 pair）
  - 确定 Proposer/Moderator 人选（准确率最高的模型）
```

### 6.2 Phase 2：辩论效果验证（1200 题全量）

**Phase 1 完成后执行**

```
核心对比:
  Single            — 最佳单模型基线
  Vote-2            — 推荐组合各自答题 → 多数投票
  Debate-2-1round   — 推荐组合辩论 1 轮
  Debate-2-2round   — 推荐组合辩论 2 轮
  Debate-2-3round   — 推荐组合辩论 3 轮
```

**决策规则**：
```
如果 Debate-2 最优轮数 > Vote-2 + 3%：
  → 辩论产生超出集成的增量，展开下面消融

如果 Debate-2 ≤ Vote-2 + 3%：
  → 辩论未产生有意义增量，论文调整为"辩论的边界条件"
```

### 6.3 Phase 3：消融实验（若 Phase 2 通过）

```
消融 1 — 智能体数量:
  Vote-3 vs Debate-3     （3 个模型辩论有增量吗？）
  Vote-4 vs Debate-4     （4 个模型辩论有增量吗？）

消融 2 — 同模型对照:
  Debate-Same-2round     （2 × 同模型辩论，验证多样性效应）
```

### 6.4 无需实验的变量

| 变量 | 结论 | 依据 |
|------|------|------|
| 拓扑结构 | 集中式适合诊断 | 见附录 A |
| 同模型辩论 | 不如跨模型 | Liang (2023) + Khan (2024)：共享盲区 |

## 7. 辩论协议设计

### 7.1 辩论流程

沿用 MADDx 集中式对抗辩论协议：

```
Step 1 — 独立诊断:
  Model_A（Proposer）独立分析病例，给出答案 + 推理依据
  Model_B（Critic）独立分析同一病例，给出自己的答案 + 推理依据

Step 2 — 首轮辩论:
  Critic 审查 Proposer 的答案和推理，基于自身知识指出分歧：
    - 答案不同 → 解释为什么自己的答案更可能
    - 答案相同但推理不同 → 指出推理中的潜在问题
  Proposer 回应 Critic 的质疑：
    - 接受正确批评 → 修正答案
    - 反驳错误批评 → 坚持原答案并解释

Step 3 — 次轮辩论（如果配置多轮）:
  Critic 对修正后的答案再做审查，Proposer 再次回应

Step 4 — Moderator 终裁:
  Model_A 综合全部辩论历史，输出最终答案
```

### 7.2 角色分配

基线评测中准确率最高的模型担任 Proposer + Moderator。互补性最强的模型担任 Critic。

### 7.3 与旧版 MADDx 的关键区别

| 维度 | 旧版 | 新版 |
|------|------|------|
| Critic 的知识来源 | KG 检索 | 自身独立诊断（跨模型知识差异） |
| KG 的角色 | 辩论参与者 | 实体验证 + 前端展示（不参与辩论） |
| 智能体模型 | 全用 DeepSeek | Model_A + Model_B 异构 |
| 输出格式 | Markdown 叙事 | 答案字母（单选）/ 逗号分隔字母（多选） |
| 辩论轮数 | 固定 2 轮 | 实验变量（1/2/3） |

## 9. 论文叙事预案

### 如果 Debate > Vote（辩论赢了）

> "实验表明，异构多模型辩论在 CMB-Exam 1200 题评测集上较单 LLM 基线提升 X%，较同数量纯投票集成提升 Y%。这验证了跨模型辩论引入了超出 ensemble 效应的认知增益——不同模型的差异化知识在辩论中产生互校正。消融实验进一步表明，N 轮辩论和 M 个模型是此场景的最优配置。"

### 如果 Debate ≤ Vote（辩论没赢）

> "实验表明，在 CMB-Exam 评测上，多模型投票集成已能捕获大部分 ensemble 增益（较单 LLM 提升 Z%），而辩论未产生超出此基线的额外提升。但我们发现辩论在其他维度上提供了投票无法提供的价值：推理可追溯性（黑板 DAG）、证据引用（工具取证记录）、以及置信度校准（辩论后模型置信度更接近实际正确率）。这些特性在临床安全场景中具有独立于准确率的价值。"

## 附录 A：集中式拓扑选择依据

### A.1 核心论文支撑

| 论文 | 出处 | 核心发现 | 对本设计的支持 |
|------|------|---------|--------------|
| **TAO** | Kim et al., MIT/Harvard, 2025 | 层级结构吸收 **24%** 个体错误，在 4/5 医疗安全基准上超越同层 **8.2%** | 直接验证临床层级优于同层讨论 |
| **UCAgents** | Feng et al., 香港中文大学, 2025 | 层级式框架超越开放式辩论，降低 **87.7%** token 成本 | 反对无结构全连接辩论 |
| **KG4Diagnosis** | Zuo et al., 剑桥大学, 2024 | 两层架构（全科→专科），覆盖 362 种疾病 | 临床层级建模先例 |
| **Sparse Topology Debate** | Li et al., 2024 | 稀疏通信在推理任务上达到全连接同等效果 | 推理不需要全连接 |
| **Information Propagation** | Shen et al., 2025 | 稀疏拓扑抑制错误传播，中等稀疏度最优 | 集中式过滤抑制错误级联 |

### A.2 论文中的写法

> "在拓扑结构的选择上，本研究采用集中式辩论拓扑。这一选择基于三个考量：
>
> （1）**临床流程对齐**：真实医疗场景中的会诊流程天然为层级式——住院医师初诊、主治医师复核、科主任终裁。TAO 系统（Kim et al., 2025）已从实验上验证了这种临床层级结构相比同层讨论在医疗安全基准上提升 8.2%；
>
> （2）**错误抑制机制**：Shen et al.（2025）从信息传播角度证明，集中式拓扑通过中央节点的信息过滤，能有效抑制错误在智能体间级联放大；
>
> （3）**效率优势**：Li et al.（2024）的实验表明，推理型任务不需要全连接通信。UCAgents（Feng et al., 2025）进一步验证了层级结构相较开放式辩论降低了 87.7% 的 token 消耗。"

## 附录 B：辩论协议的跨任务可复用性

### B.1 协议与领域的分离

本研究的集中式辩论协议（Proposer → Critic → Defender → Moderator）是**领域无关的通用框架**。协议核心组件——黑板追溯、受限 ReAct 工具取证、收敛规则——在跨任务迁移时保持完整。唯一需要替换的是每个角色的 system prompt。

### B.2 跨任务映射

| 子任务 | Proposer 角色 | Critic 角色 | 辩论分歧来源 |
|--------|-------------|------------|-------------|
| 症状诊断 | 给出 Top-3 诊断 | 独立诊断 + 找分歧 | 两个模型给出不同诊断 |
| 辟谣求证 | 判定谣言真假 | 独立判定 + 质疑证据链 | 对同一说法的判断不同 |
| 用药审查 | 评估用药安全性 | 独立评估 + 质疑遗漏风险 | 对禁忌/相互作用判断不同 |
| 报告解读 | 解读检查结果 | 独立解读 + 挑数值遗漏 | 数值解读偏好不同 |

### B.3 共享基础设施

- **Blackboard**：append-only 辩论日志，版本化 DAG 溯源
- **agent_loop**：受限 ReAct 循环，工具预算控制 + 防发散熔断
- **ToolRegistry**：KG / RAG / Web Search 统一工具接口
- **收敛协议**：MAX_ROUNDS / TOP1_STABLE / NO_VALID_OBJECTIONS / NO_NEW_EVIDENCE

### B.4 论文中的写法

> "本研究提出的集中式辩论协议不仅是针对症状诊断的单一解决方案，而是一个通用的医疗多智能体协作框架。通过替换角色 prompt，同一协议可被复用到辟谣求证、用药审查、报告解读等多个医疗子任务。协议中的黑板追溯机制、受限工具取证协议和收敛判断规则在跨场景迁移时保持完整——这种'协议不变，知识注入'的设计模式是本研究架构层面的核心贡献。"
